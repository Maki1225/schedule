# 開発者ガイド

## 1. インストール (初回のみ)

### frontend のセットアップ
```bash
cd frontend/
npm install
cd ..
```

### backend のセットアップ
```bash
cd backend/
npm install
cd ..
```

## 2. 開発サーバーの起動

### frontend の起動
```bash
cd frontend/
npm run dev
```

### backend の起動
```bash
cd backend/
npm run dev
```

## 3. 環境変数 (backend/.env)

```env
DATABASE_URL="your_database_url"
JWT_SECRET="your_jwt_secret"
GOOGLE_CLIENT_ID="your_google_client_id"
```
