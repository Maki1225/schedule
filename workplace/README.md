# Schedule Management App

## 📋 概要
Google認証を使用したスケジュール・課題管理アプリケーション。

## 🎉 主な機能
- Google OAuth認証
- カレンダー表示
- 課題・予定管理
- ダッシュボード表示
- レスポンシブデザイン

## 🛠️ 技術スタック
**Frontend:** HTML, CSS, JavaScript (Vanilla)
**Backend:** Node.js, Hono, TypeScript
**Database:** PostgreSQL (Neon)
**Authentication:** Google OAuth 2.0
**Deployment:** Vercel
